FabLab Cost Optimizer

FabLab Cost Optimizer is a desktop application created during the Java module of the Digital FabLab program. It helps users quickly estimate the total cost of a FabLab project by calculating material, machine and additional costs.

Technologies Used

Java JavaFX FXML CSS OOP

Key Features

  • Material cost calculation
  • Machine time and machine rate calculation
  • Additional cost support
  • Automatic estimated total calculation
  • Simple and user-friendly JavaFX interface
  • Cost recommendation based on project estimate

PROJECT OVERVIEW

How the application works

The user enters the material cost per piece, number of pieces, machine operating time, machine rate per minute and other expenses. The application then calculates the material cost, machine cost and estimated total project cost automatically.

CALCULATION

Cost Estimation

Material Cost = Material Cost per Piece × Number of Pieces

Machine Cost = Machine Time × Machine Rate per Minute

Total Cost = Material Cost + Machine Cost + Other Cost
